# RiverMind v0.2 双人记忆评估

运行日期：2026-10-05。评估主体是无模型的规则陪练，使用三个教学规则对手；报告只包含合成实验汇总，不包含真实训练手牌或个人数据。

## 复现命令

```sh
npm run eval:heads-up -- --pairs=50 --seeds=7,17,29,43,71 --trials=100
```

需要源码及开发依赖。默认报告位于 `.data/evaluations/heads-up.json`，不提交训练目录。完整本轮汇总见 [JSON 报告](evaluation/heads-up-v0.2.json)。同种子可复现收益和引用次数，耗时会随机器负载变化。

## 实验设计

- 三种记忆：`none` 不暴露画像；`aggregate` 只用旧累计统计；`conditional` 使用匹配条件和区间。阈值调整幅度相同。
- 三种规则对手：`fold-heavy` 偏向弃牌，`calling-station` 倾向跟注，`pressure` 倾向施压；没有经过职业水平校准。
- 每组五个独立 seed，每个 seed 五十对牌；相同牌组交换庄位，每组共 500 手，总计 4,500 手。
- 每手双方 100BB 起始筹码；各“对手 / 模式 / seed”有独立画像。第二手可使用第一手的公开行为，顺序各组一致；不保存私有牌或公共牌到画像。
- 发牌和胜率抽样使用分开的随机流。每手的画像直到结束才更新，不使用当前手结果；不访问真实 DSH 会话或现有训练目录。

## 结果

| 对手 | 记忆模式 | bb / 100 手 | 引用次数 | 合法提交率 | 兜底率 |
| --- | --- | ---: | ---: | ---: | ---: |
| fold-heavy | none | 29.73 | 0 | 100% | 0% |
| fold-heavy | aggregate | 32.56 | 137 | 100% | 0% |
| fold-heavy | conditional | 29.49 | 7 | 100% | 0% |
| calling-station | none | 190.02 | 0 | 100% | 0% |
| calling-station | aggregate | 190.02 | 0 | 100% | 0% |
| calling-station | conditional | 190.02 | 0 | 100% | 0% |
| pressure | none | 1619.95 | 0 | 100% | 0% |
| pressure | aggregate | 1619.95 | 0 | 100% | 0% |
| pressure | conditional | 1619.95 | 0 | 100% | 0% |

bb / 100 手以 Iris 的净筹码除以大盲，再按一百手归一化；平局在胜率中计 0.5。合法率与兜底率统计 Iris 的实际行动，不包含人类规则对手。

对偏向弃牌的规则对手，累计统计较无记忆变化为 +2.83 bb / 100，五个 seed 的差值范围为 −3.65～+6.00；条件画像变化为 −0.24，范围为 −1.20～0。其他两类对手没有触发记忆调整，三组收益相同。

**本轮没有证明条件画像提高收益。** 条件划分与区间门槛减少了可用样本，条件组只出现七次引用；更细的画像首先改善证据表达，当前策略如何利用这些证据仍需进一步设计和验证。

## 结果的适用范围

- 这些是教学规则对手和手工阈值策略；较高收益不能代表真人或专业 AI 水平。
- seed 差值范围不是统计置信区间，少量 seed 和有限样本不足以证明稳定改善。
- 批量规则测试没有模型故障、延迟、token 使用或模型费用；`modelTokens: null` 表示未测量，不能解释为模型用量为零。
- 当前 DSH 正常对局仍复用会话；未来模型实验需要控制每手上下文，避免无记忆组通过对话历史获得信息。
- 下一轮应扩充样本，分析条件稀疏，再在独立保留 seed 上验证策略修改；不根据单次结果宣称自主学习。
